# 塔羅與雷諾曼

純前端牌卡占卜網頁，不需安裝或建置。

| 檔案 | 內容 |
|---|---|
| `index.html` | 入口頁，連到塔羅、雷諾曼與易經起卦 |
| `tarot.html` | 塔羅 78 張：今日一牌、三張牌（過去・現在・未來）或一張、牌庫 |
| `lenormand.html` | 古典雷諾曼 36 張：今日一牌、三張牌、大牌陣 9×4、牌庫 |

## 範圍與限制

- 塔羅只使用正位；雷諾曼本身不分正逆位。
- 塔羅牌面為 `cards/` 資料夾內 78 張 AI 生成的新藝術風格圖片，檔名格式 `major-00-fool.png`、`wands-01-ace.png`（花色-序號-英文名）；雷諾曼為程式排版，加撲克牌角標。
- 雷諾曼牌序與撲克牌對應依常見的 36 張 Petit Lenormand 排列。
- 大牌陣 9×4 只排出牌位、標出代表牌（女士 29／男士 28）與上下左右相鄰牌，不自動產生整體解讀，也不含宮位讀法。
- 今日一牌依瀏覽器本機日期計算；其他抽牌使用 `crypto.getRandomValues`，結果不儲存、不送出資料。
- 牌義為依傳統整理的象徵性解讀，無法以科學方法驗證，不構成醫療、法律或財務判斷。
