# 塔羅與雷諾曼

純前端牌卡占卜網頁，不需安裝或建置。

| 檔案 | 內容 |
|---|---|
| `index.html` | 入口頁，連到塔羅、雷諾曼與易經起卦 |
| `tarot.html` | 塔羅 78 張：今日一牌、三張牌（過去・現在・未來）或一張、牌庫 |
| `lenormand.html` | 古典雷諾曼 36 張：今日一牌、三張牌、大牌陣 9×4、牌庫 |
| `theater.html`、`theater-data.js` | 雷諾曼小劇場：手動選三張牌，依牌序演出三幕互動故事（兩次選擇、四種結局）；劇情為本地資料，不需後端 |
| `style.css` | 三頁共用的色彩與版面樣式（只用系統字型，不連外部字型服務） |
| `tabs.js` | 分頁切換，含方向鍵與無障礙屬性 |

## 範圍與限制

- 塔羅只使用正位；雷諾曼本身不分正逆位。
- 塔羅 78 張與雷諾曼 36 張的牌面，都是 `cards/` 資料夾內 AI 生成的新藝術風格 WebP 圖片，另有 400px 縮圖放在 `cards/thumb/`（頁面實際讀取的是縮圖），檔名格式 `major-00-fool.webp`、`wands-01-ace.webp`、`lenormand-01-rider.webp`（類別-序號-英文名）；雷諾曼圖上已有撲克牌角標。
- 雷諾曼牌序與撲克牌對應依常見的 36 張 Petit Lenormand 排列。
- 大牌陣 9×4 只排出牌位、標出代表牌（女士 29／男士 28）與上下左右相鄰牌，不自動產生整體解讀，也不含宮位讀法。
- 今日一牌依瀏覽器本機日期計算；其他抽牌使用 `crypto.getRandomValues`，結果不儲存、不送出資料。
- 雷諾曼小劇場的故事是依牌面象徵自行創作的虛構情節，不是占卜結果，也不是傳統牌義原文；全程不抽牌、不洗牌。
- 牌義為依傳統整理的象徵性解讀，無法以科學方法驗證，不構成醫療、法律或財務判斷。
