# 七十八張塔羅

純前端塔羅抽牌網頁，單一 `index.html`，不需安裝或建置。

## 功能

- **今日一牌**：依瀏覽器本機日期計算，同一天顯示同一張，隔天更換。
- **抽牌**：可輸入問題（可留白），抽三張（過去・現在・未來）或抽一張。使用瀏覽器 `crypto.getRandomValues`，不重複抽牌。
- **牌庫**：78 張全列，可依大阿爾克那與四花色篩選，點牌查看牌義。

## 範圍與限制

- 只使用正位，不含逆位。
- 牌面是程式繪製的抽象 SVG，不使用圖片或 AI 生成圖。
- 牌義為依塔羅傳統整理的象徵性解讀，無法以科學方法驗證，也不構成醫療、法律或財務判斷。
- 抽牌結果不儲存，重新整理即消失；不會送出任何資料。

## 使用

直接用瀏覽器開啟 `index.html`，或透過 GitHub Pages 瀏覽。
